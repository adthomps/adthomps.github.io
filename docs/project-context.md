## Architecture

Four self-contained static HTML pages with inline styling and no loaders; the launch page and 404 page link out to the maintained APT site, the Authorize.Net integration toolbox, and GitHub.

- index.html is the launch page with links to appliedpracticalthinking.com, https://apt-anet-integration-toolbox.pages.dev/, and https://github.com/adthomps.
- privacy.html and terms.html are static legal/support pages kept while the site remains public.
- 404.html is the static GitHub Pages fallback and links back to index.html and the maintained destinations.

- Runtime model: Static files served as-is by GitHub Pages in the visitor's browser; there is no server-side code, build output, or runtime dependency.
- Deployment model: GitHub Pages publishes the repository root from the main branch; pushing to main updates the live site. The only workflow is the APT check (.github/workflows/apt-check.yml).
