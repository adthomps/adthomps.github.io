# Project Context

## Purpose

A small GitHub Pages static gateway. It keeps a launch page and legal/support HTML, and points traffic at maintained destinations instead of hosting product, docs, or demo trees.

## Boundary

This repository owns `index.html`, `privacy.html`, `terms.html`, and `404.html`. It does not own Authorize.Net toolbox demos, public APT portfolio content, or canonical doctrine.

## Operating rules

- Do not rebuild payment or integration demos here.
- Send public APT material to `applied-practical-thinking` and reusable standards to `apt-principles-agents`.
- Ask before implementing when the page or destination is unclear.

## Local Cloudflare

Status: Not a Cloudflare app.

Local command: open `index.html` in a browser. This is a GitHub Pages static site with no build step.

Fix: none.
